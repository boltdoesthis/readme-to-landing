README → Landing

Paste a README or product blurb. Get a clean, downloadable single-page landing HTML. No accounts, no paid APIs, nothing leaves your browser.

What this extracts (and how to get better results)

The generator looks for a title (# Heading), short description, bullet feature lists, a price hint ($29), and a CTA link (first markdown/http link or a Gumroad-style URL). Plain paragraphs become the hero body. Use a short README with a clear H1, 3–6 bullets, and one link for best results.

  • Works offline after first load — all parsing is local JavaScript.
  • Download the HTML and host it on GitHub Pages, Cloudflare Pages, Netlify, or any static host.
